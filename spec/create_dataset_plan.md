## 脚本设计：`scripts/create_dataset.py`

### 命令行参数

```
python scripts/create_dataset.py \
  --source Root/03_label_check \      # 标注数据源目录
  --name 0002_20270812 \              # 数据集名称
  --dataset-dir Root/04_dataset \     # 数据集输出根目录
  --classes Root/00_config/classes.txt \  # 类别文件路径
  --split 7 2 1 \                     # 训练/验证/测试 比例
  --pos-neg-ratio 9 1 \               # 正样本/空样本 比例
  --seed 42                           # 随机种子（可复现）
```

所有参数都有默认值，与 `raw_spec.txt` 中的默认值一致。

### 处理流程

1. **加载类别**：从 `--classes` 文件读取，跳过 `#` 开头的注释行，构建 `{类别名: class_id}` 映射
2. **扫描数据源**：递归查找 `03_label_check/` 下所有 `场景名/视频名/` 目录
3. **收集样本**（每个视频目录内）：
   - 遍历所有 `.jpg` 文件
   - 查找同名 `.txt` 文件
   - 如果 `.txt` 缺失但存在 `.json` → 自动从 JSON 转为 YOLO txt 格式
   - 如果 `.txt` 缺失但存在 `.xml` → 自动从 XML 转为 YOLO txt 格式（预留）
   - **规则(2)**：没有对应 `.jpg` 的标注文件直接跳过
   - 分类：非空 `.txt` = 正样本，空 `.txt` = 空样本
4. **随机打乱**：正样本和空样本分别用 `--seed` 随机打乱
5. **拆分正样本**：按 `--split` 比例（7:2:1）分配到 train/val/test
6. **计算空样本数量**：每个子集中 `空样本数 = round(正样本数 / 比例分子 × 比例分母)`，不超过可用空样本数
7. **选取空样本**：随机选取空样本分配给各子集
8. **创建输出目录**：`{dataset-dir}/{name}/images/{train,val,test}/` 和 `labels/{train,val,test}/`
9. **复制文件**：按统一命名规则复制图片和标注到对应目录
10. **生成 data.yaml**：包含相对路径、各子集路径、类别映射

### 关键设计决策

- **比例严格控制**：用户确认"比例需要严格控制"。以当前 23 正样本为例，7:2:1 拆分 → train=16正+2空, val=5正+1空, test=2正+1空。未使用的空样本保留在源目录中不动。
- **相对路径**：`data.yaml` 中使用相对路径，`path: .`，方便移植。
- **文件命名**：`{场景}_{视频}_{原始帧名}.{扩展名}` 确保跨视频不冲突。
- **JSON→TXT 转换**：仅处理 `shape_type: "rectangle"` 的标注，将像素坐标转换为 YOLO 归一化格式：`class_id 中心x/宽 中心y/高 框宽/宽 框高/高`
- **可复现性**：`--seed` 控制所有随机操作，同一参数多次运行结果一致。
- **脚本可复用**：后续创建其他数据集只需改参数即可。

### 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| 有 `.json` 无 `.txt` | 自动从 JSON 矩形标注转为 YOLO txt |
| 有 `.xml` 无 `.txt` | 自动从 XML 转为 YOLO txt（为未来预留） |
| 有标注无对应 `.jpg` | 跳过，打印警告（规则2） |
| 空样本不够满足比例 | 全部使用，打印警告 |
| 某子集正样本为 0 | 跳过该子集目录的创建 |
| JSON 中出现未知类别 | 打印警告，跳过该标注框 |
| JSON 中非矩形标注 | 打印警告，跳过（YOLO 只支持矩形框） |
